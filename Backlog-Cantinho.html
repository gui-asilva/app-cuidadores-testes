Backlog do Cantinho

Todas as funcionalidades desenhadas no protótipo, por fase e área. Abra uma funcionalidade para criar as tarefas de implementação, dar um responsável e um prazo, e acompanhar o andamento.

Use as setas para subir ou descer uma área ou uma funcionalidade. Os códigos se renumeram sozinhos. Toque em "Pronto" quando terminar.

Carregando as funcionalidades. Quando o quadro abrir, toque numa funcionalidade e use "Adicionar tarefa".

Toque no estado de uma tarefa para avançar: A fazer → Fazendo → Feito. Título, responsável e prazo salvam ao sair do campo. Use "Nova funcionalidade" para incluir algo que ainda não está na lista. Nesta versão local, tudo fica salvo neste navegador. Use "Exportar dados" para guardar uma cópia ou levar para outro computador.
